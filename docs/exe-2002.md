# The 2002 executable (current target)

`WINO/Grand Theft Auto.exe` from the Steam release and the free 2002
Rockstar Classics release — byte-identical in both.
SHA-1 `d36976d66599cd649bf24f8ccd45bda84c0ee3f8`, 774,144 bytes.

It is the target because anyone can obtain it legally for free; the 1997 CD
build ([exe-1997.md](exe-1997.md)) is only on the original disc.

Reproduce everything here with `tools/lift.sh`.

## Image

* PE32 GUI, linked 2002-11-11 with Microsoft linker 6.0 (Visual C++ 6),
  CRT statically linked, SciTech MGL statically linked (same as 1997).
* Image base `0x400000`, entry `0x49DC30`.
* **No relocation table.** The image must live at `0x400000` (pcrecomp maps
  it there anyway); pointers have to be found by analysis rather than read
  from `.reloc`.
* No `.idata`: the import table and IAT (`0x4A7000`) live in `.rdata`.

| Section | VA | Virtual size | Raw size | Perms |
| --- | --- | --- | --- | --- |
| `.text` | `0x401000` | `0xA53D9` | `0xA6000` | r-x |
| `.rdata` | `0x4A7000` | `0x3ABA` | `0x4000` | r-- |
| `.data` | `0x4AB000` | `0x2E5298` | `0x11000` | rw- (≈3 MB, mostly BSS) |
| `.rsrc` | `0x791000` | `0x8B0` | `0x1000` | r-- |

Static imports: 166 functions from the same 8 DLLs as the 1997 build
(Miles drops from 45 to 38 functions: no Red Book CD audio, music is WAV).

## Function discovery

| | pcrecomp `disasm32` | joyride `tools/funcs.py` |
| --- | --- | --- |
| Function starts | **2,295** | 2,028 |
| Aliases (labels inside a body that need a dispatch entry: switch cases, stored code pointers) | 4,330 | — |
| `.text` coverage | 95.7 % | 91.8 % |
| Agreement | 1,938 starts found by both | |

pcrecomp finds 383 starts the simpler pass misses; joyride's pass finds 90
(stored-pointer guesses) that pcrecomp treats differently. pcrecomp's catalog
is the one used for lifting; `funcs.py` stays as a cross-check.

## Lift

`python -m tools` (pcrecomp, submodule at `external/pcrecomp`):

* 6,638 entry points lifted in ~90 s into 7 source files + dispatch table,
  ≈3.5 M lines / 161 MB of C.
* **0 unsupported instructions**, and every file parses with
  `gcc -m32 -fsyntax-only` against `runtime/recomp32`.
